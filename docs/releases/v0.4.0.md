# v0.4.0 Workflow Pack With Portable Prompts

Release date: 2026-07-04

## Summary

This minor release expands Loop Engineering from a Codex-only skill pack into a
broader workflow pack. Codex users still get the installable skill, while users
of Cursor, Claude Code, Gemini CLI, ChatGPT, JetBrains AI, and similar AI coding
tools can use the new Portable Prompt Pack without installing Codex.

## Highlights

- Add `portable/README.md` with a no-Codex-required usage path.
- Add English and Chinese portable prompts:
  - `portable/LOOP_ENGINEERING_PROMPT.md`
  - `portable/LOOP_ENGINEERING_PROMPT.zh.md`
- Add `portable/AGENTS_TEMPLATE.md` for tools that support project instruction
  files.
- Add `portable/STATE_TEMPLATE/` with reusable state templates:
  - `triage.md`
  - `decisions.md`
  - `failures.md`
  - `inbox.md`
  - `next.md`
- Add portable examples for vague ideas and existing-project continuation.
- Update README, promotion material, release helper defaults, and showcase
  documentation around the workflow pack positioning.
- Keep deterministic offline evals and repository contract tests token-free.

## Installation

Codex skill path:

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo zq88577727/loop-engineering-skill \
  --ref v0.4.0 \
  --path skills/loop-engineering
```

Restart Codex after installation.

Portable path:

```text
Open portable/README.md, copy portable/LOOP_ENGINEERING_PROMPT.md or
portable/LOOP_ENGINEERING_PROMPT.zh.md, then copy portable/STATE_TEMPLATE/ into
your project as state/.
```
