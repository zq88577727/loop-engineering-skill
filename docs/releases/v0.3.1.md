# v0.3.1 Patch Release With Agent Router Initializer

Release date: 2026-07-04

## Summary

This patch release makes the improved project initializer available to external
users by default. It keeps the `v0.3.0` public-ready skill pack and live eval
harness unchanged, then updates the generated `AGENTS.md` template so newly
initialized projects start with a short router, verification entry point, hard
constraints, and explicit file map.

## Highlights

- Recommend `--ref v0.3.1` in the README install command.
- Update the initializer-generated `AGENTS.md` to include:
  - `Run It`
  - `Verify It`
  - `Hard Constraints`
  - `Where To Look`
- Route new agents to the canonical project state files:
  - `state/next.md`
  - `state/triage.md`
  - `state/decisions.md`
  - `state/failures.md`
  - `state/inbox.md`
  - `docs/acceptance.md`
  - `docs/architecture.md`
- Add a repository contract test that keeps the generated `AGENTS.md` short,
  navigable, and verification-oriented.
- Keep default CI token-free with deterministic offline evals.
