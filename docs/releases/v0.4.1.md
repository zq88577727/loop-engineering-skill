# v0.4.1 Outcome-Gated Continuation Guidance

Release date: 2026-07-05

## Summary

This patch release makes `v0.4.1` the recommended stable baseline for external
users. It includes the Project Outcome Gate continuation guidance that was added
after `v0.4.0`, so users who copy the README install command no longer receive
an older tag that still encourages stale `state/next.md` continuation.

## Highlights

- Update README, showcase, promotion material, validator checks, and release
  helper defaults from `v0.4.0` to `v0.4.1`.
- Keep Loop Engineering positioned as a lightweight workflow pack: Codex skill
  plus Portable Prompt Pack.
- Reinforce that `state/next.md` is a candidate next step, not the highest
  instruction.
- Require Project Outcome Gate before continuing an existing project.
- Add a forward-test sample where stale `state/next.md` is rejected because it
  does not advance the user-visible demo or business acceptance.
