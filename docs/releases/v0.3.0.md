# v0.3.0 Public-Ready Skill Pack With Live Eval Harness

Release date: 2026-07-04

## Summary

This release is the recommended stable version for external users. It keeps the
public-ready install path from `v0.2.1` and adds an automated behavior eval
harness that can validate both deterministic offline scenarios and real Codex
session behavior.

## Highlights

- Recommend `--ref v0.3.0` in the README install command.
- Keep the three offline eval scenarios:
  - vague idea -> clarify and scaffold state
  - existing project -> continue one bounded loop from state
  - premature implementation pressure -> reject coding too early
- Add a live eval runner that starts real `codex exec` sessions in temporary
  workspaces and validates the files those sessions write.
- Add live eval support for repeated samples with `--samples`.
- Add live eval support for a model matrix with `--models`.
- Add failure sample archiving under `evals/reports/failures/*.json`.
- Add stronger semantic validation for loop state, human decision points,
  bounded next-loop verification, existing-state continuation, and premature
  implementation rejection.
- Keep default CI token-free by running the offline eval only.
