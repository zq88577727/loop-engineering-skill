# v0.4.2 Explicit Human Gate

Release date: 2026-07-16

## Summary

This patch release adds an explicit `human gate` field to the Loop Engineering
workflow pack contract. The goal is to make approval boundaries visible in every
loop, instead of relying on implicit judgment around irreversible, sensitive,
external, or high-stakes actions.

## Highlights

- Extend the loop contract from:

```text
ship/stop gate:
```

to:

```text
ship/stop gate:
human gate:
```

- Define `human gate` as actions that require explicit human approval before
  execution, including destructive operations, external publishing, credential
  changes, and high-stakes domain decisions.
- Sync the Codex skill, full workflow reference, initializer-generated
  `AGENTS.md`, Portable Prompt Pack, README, validator, and tests.
- Keep the existing Project Outcome Gate, `state/next.md` candidate rule, loop
  budget, and ship/stop behavior unchanged.
