# v0.2.0 Public-Ready Skill Pack

Release date: 2026-07-03

## Summary

This release turns Loop Engineering from a minimal personal Codex skill into a
public-ready skill pack with CI, examples, stronger validation, and a stable tag
installation path.

## Highlights

- Add GitHub Actions validation workflow.
- Add public examples for vague idea handling, existing project continuation, and
  invalid loop patterns.
- Strengthen repository validation with public-ready contract checks.
- Add unittest coverage for validator and initializer behavior.
- Add initializer `--dry-run` support.
- Document stable tag installation with `--ref v0.2.0`.
