# Next Loop

## Next Goal

Create the smallest browser-extension proof that saves one selected snippet.

## Entry Condition

The user accepts or revises the assumptions in `state/decisions.md` and answers
the questions in `state/inbox.md`.

## Task

Create a minimal extension structure for the selected browser with one capture
path and local storage.

## Verification

Run the extension locally, save one selected snippet, reload the page or
extension view, and confirm the snippet remains available.

## Stop Condition

Stop after one snippet can be saved and verified. Do not add search, sync,
accounts, or export unless a later loop explicitly selects them.
